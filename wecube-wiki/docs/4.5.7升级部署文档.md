WeCube v4.5.7升级部署文档
在这里，我们将为您说明如何把您的wecube从v4.5.6升级到v4.5.7。

升级说明
platform-core：
docker pull ccr.ccs.tencentyun.com/webankpartners/platform-core:v4.5.7
升级ddl: https://github.com/WeBankPartners/wecube-platform/blob/master/platform-core/wiki/database/v4.5.7.sql
wecube-portal：
docker pull ccr.ccs.tencentyun.com/webankpartners/wecube-portal:v4.5.7
platform-auth-server：
docker pull ccr.ccs.tencentyun.com/webankpartners/platform-auth-server:v4.5.7
platform-gateway：
docker pull ccr.ccs.tencentyun.com/webankpartners/platform-gateway:v4.5.7
