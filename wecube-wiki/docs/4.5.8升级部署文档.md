WeCube v4.5.8升级部署文档
在这里，我们将为您说明如何把您的wecube从v4.5.7升级到v4.5.8。

升级说明
platform-core：
docker pull ccr.ccs.tencentyun.com/webankpartners/platform-core:v4.5.8
升级ddl: https://github.com/WeBankPartners/wecube-platform/blob/master/platform-core/wiki/database/v4.5.8.sql
wecube-portal：
docker pull ccr.ccs.tencentyun.com/webankpartners/wecube-portal:v4.5.8
platform-auth-server：
备注：auth镜像的http服务端口从8080改成了8002，升级时需要在docker compose yml里改下端口映射
docker pull ccr.ccs.tencentyun.com/webankpartners/platform-auth-server:v4.5.8
platform-gateway：
docker pull ccr.ccs.tencentyun.com/webankpartners/platform-gateway:v4.5.8
